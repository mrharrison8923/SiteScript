Telegram Group Greeter

Автоматичне привітання нових учасників у групі

Завантаження

Оберіть потрібні файли для завантаження:


Termux (F-Droid) Termux:Widget greet_bot.py profiles.json requirements.txt

Швидкий старт

1. Встановіть Termux

Завантажте Termux з F-Droid (не з Google Play).

2. Встановіть залежності

Відкрийте Termux і виконайте:

pkg update && pkg upgrade -y
pkg install python -y

3. Скопіюйте файли

Покладіть файли у папку ~/Downloads/ на телефоні.

4. Встановіть Python-залежності

cd ~/Downloads
pip install -r requirements.txt

5. Запустіть

python greet_bot.py

Способи авторизації

  • QR-код — швидко, відскануйте з телефона
  • Код на email — якщо SMS платне, введіть email і отримайте код
  • Код на номер телефону (SMS) — стандартний спосіб

Також скрипт запитає, чи встановлений Telegram на пристрої.

Готово! При першому запуску оберіть спосіб авторизації.

Налаштування віджета

Для запуску одним тапом на робочому столі:


mkdir -p ~/.termux/widgets
cat > ~/.termux/widgets/greeter.sh << 'EOF'
#!/data/data/com.termux/files/usr/bin/sh
cd ~/Downloads
python greet_bot.py
EOF
chmod +x ~/.termux/widgets/greeter.sh

Після цього додайте віджет Termux:Widget на робочий стол.

Налаштування батареї

Щоб скрипт не зупинявся системою:

  • Налаштування > Батарея > Оптимізазація → Не оптимізувати Termux
  • Налаштування > Додатки > Termux > Автозапуск → Увімкнути

Додавання акаунтів

При запуску скрипт показує меню вибору профілю. Ви можете:

  • Вибрати існуючий акаунт
  • Додати новий акаунт (потрібні API_ID, API_HASH, номер телефону, ID групи, текст привітання)

Профілі зберігаються у файлі profiles.json.

Текст привітання

Ви можете змінити текст привітання для кожного акаунта. Використовуйте {name} для підстановки імені користувача:

  • Хелов, {name}.
  • Привіт, {name}!
  • Ласкаво просимо, {name}!

Режим згадування

Оберіть, як згадувати нового користувача:

  • За ім'ям/username — привітання в тексті повідомлення
  • Відповіддю на повідомлення про приєднання — привітання як reply на службове повідомлення

Отримання API_ID та API_HASH

  1. Перейдіть на my.telegram.org
  2. Увійдіть за номером телефону
  3. Виберіть API development tools
  4. Створіть новий додаток і отримайте API_ID та API_HASH

Отримання ID групи

Спосіб 1: Через @userinfobot

  1. Відкрийте @userinfobot у Telegram
  2. Надішліть йому будь-яке повідомлення з групи (перешліть)
  3. Бот поверне ID групи

Спосіб 2: Через @getmyid_bot

  1. Додайте @getmyid_bot у групу
  2. Напишіть будь-яке повідомлення в групу
  3. Перешліть це повідомлення боту — він поверне ID групи

Спосіб 3: Через веб-версію Telegram

  1. Відкрийте web.telegram.org
  2. Перейдіть у групу
  3. Подивіться в адресний рядок — там буде ID групи
Важливо: ID групи має бути від'ємним числом, наприклад: -1001234567890
Важливо: Ніколи не повідомляйте свій API_HASH, номер телефону або пароль 2FA іншим людям!

Вирішення проблем

Скрипт не запускається

Переконайтеся, що встановлені всі залежності: pip install -r requirements.txt

QR-код не з'являється

Перезапустіть скрипт. Переконайтеся, що ви використовуєте правильний номер телефону.

Скрипт зупиняється через деякий час

Перевірте налаштування батареї (див. вище).

Помилка FloodWait

Зачекайте вказаний час і спробуйте знову.
